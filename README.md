# yam — «Моя волна» Яндекс Музыки в терминале

Лёгкий терминальный плеер для радиостанций Яндекс Музыки (по умолчанию — «Моя волна»).
Работает через официальный публичный API и mpv, без Electron: занимает минимум оперативной памяти и стартует мгновенно.

## Возможности

- Перебор рекомендаций станции одной за другой (радио)
- Прямые ссылки на стрим с лучшим доступным битрейтом (non-preview)
- Управление с клавиатуры прямо в терминале
- Добавление трека в «Мне нравится» одной клавишей
- Индикатор позиции трека «прошло / всего» (`01:23 / 03:42`), обновляется в одной строке терминала
- Автоматическое обновление OAuth-токена, первичная авторизация — device flow
- Отправка фидбека (trackStarted / trackFinished / skip) радиостанции

## Требования

- Go 1.21+ (для сборки; можно использовать готовый бинарник)
- mpv в PATH
- Подписка Яндекс Музыки (станция «Моя волна» доступна только платным пользователям)

## Сборка

```bash
go build -o yam .
```

## Первый запуск

```bash
./yam
```

При первом запуске запросят OAuth-авторизацию (device flow):

1. Откройте указанную ссылку в браузере: https://oauth.yandex.ru/device
2. Введите код из терминала
3. Подтвердите доступ — токен сохранится в `~/.config/yam-radio/token.json`

Дальше авторизация проходит автоматически (refresh-токен), повторный ввод кода не нужен.

## Управление

| Клавиша | Действие |
|---------|----------|
| `1` | пауза / продолжить |
| `2` | следующий трек |
| `3` | добавить текущий трек в избранное |
| `q` или `Ctrl+C` | выйти |

Справка выводится при каждом запуске.

## Флаги

| Флаг | Описание |
|------|----------|
| `--station <id:tag>` | другая радиостанция, например `--station genre:jazz` |
| `--list-stations` | вывести список доступных станций |
| `--check` | smoke-тест без звука: токен → трек станции → ссылка на стрим |

## Конфигурация

По умолчанию используются публичные OAuth-креды официального Android-приложения
Яндекс.Музыки (те же, что в open-source библиотеке [yandex-music](https://pypi.org/project/yandex-music/))
и соль подписи прямых ссылок на MP3 из того же приложения. Это не личные
секреты, а константы распространяемого приложения; значения можно
переопределить переменными окружения:

| Переменная | Описание |
|------------|----------|
| `YAM_OAUTH_CLIENT_ID` | OAuth client_id (device flow) |
| `YAM_OAUTH_CLIENT_SECRET` | OAuth client_secret |
| `YAM_SIGN_SALT` | Соль для подписи прямых ссылок на MP3 |
| `YAM_DEDUP_WINDOW` | Сколько последних треков сессии не повторять (по умолчанию 100) |

## Как это работает

1. `GET /account/status` — проверка токена, получение uid
2. `GET /rotor/station/{station}/tracks` — очередь рекомендаций (пачка по несколько треков, дальше — по `?queue=<предыдущий трек>`)
3. `GET /tracks/{id:album}/download-info` — выбор лучшего non-preview битрейта
4. `GET {downloadInfoUrl}` — XML с хостом и путём, из которых собирается прямая MP3-ссылка с подписью (md5)
5. mpv воспроизводит ссылку; плеер держит IPC-сокет для паузы

## Ограничения

- Фидбек станции отправляется best-effort: для станции `user:onyourwave` API может отвечать
  `400 "condition is not met"` — это не влияет на воспроизведение, но рекомендации
  могут не обучаться на пропусках
- Один токен = один аккаунт; для другого пользователя — удалите `~/.config/yam-radio/token.json`
- OAuth client id/secret и `signSalt` — публичные значения из официального Android-приложения
  (см. [Конфигурация](#конфигурация)), это не личные секреты
